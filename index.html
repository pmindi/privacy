Crime Documentary Automation

A personal tool for publishing and analyzing one creator's own YouTube crime-documentary videos.

What this application does

Crime Documentary Automation is a private, single-operator application that automates the production workflow of one YouTube creator's crime-documentary channel. It performs three functions, all against the operator's own Google/YouTube account only:

  • Upload: publishes the operator's finished video files to the operator's own YouTube channel on a schedule.
  • Manage: sets titles, descriptions, and other metadata on the operator's own videos.
  • Analyze: reads view, watch-time, retention, and revenue statistics for the operator's own channel to guide future content decisions.

Who uses it

The application is operated privately by a single individual creator. It is not a public product, is not offered to other users, and does not access data belonging to anyone other than its operator.

Which Google data it uses

When authorized, the application requests the following Google API scopes, used solely against the operator's own account:

  • youtube.upload — upload video files to the operator's channel.
  • youtube.force-ssl — manage the operator's own videos, metadata, and comments.
  • yt-analytics.readonly — read view, watch-time, and retention statistics.
  • yt-analytics-monetary.readonly — read monetary/revenue statistics.

Full details of how this data is handled are in the Privacy Policy.
